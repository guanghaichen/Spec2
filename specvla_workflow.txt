基本已经把这条 SpecVLA（把 EAGLE2 式投机解码用到 OpenVLA 动作 token）workflow 的关键链路和关键实现点串清楚了。下面按“离线训练→在线推理”给一个可复用的总结（以代码为准，不做超出代码的臆测）。

**1) 离线数据生成（为 Draft 训练准备监督信号）**
- 入口：`openvla/specdecoding/train-scripts/ge_data_all_openvla_token_only_libero_goal.py`
- 做的事：对 RLDSDataset 的每条样本（单帧图像 + 语言指令）调用 `model.predict_action(return_hidden_states=True, do_sample=False)`。
- 保存内容（每个样本一个 `.ckpt`）：`input_ids`、`pixel_values`、`predicted_tokens`（7 个动作 token）、以及 `hidden_state=(first_layer_hidden_list, last_layer_hidden_list)`。
  - `first_layer_hidden_list`：每个自回归步的第 0 层 hidden（近似 embedding/浅层表征）
  - `last_layer_hidden_list`：每个自回归步的最后一层 hidden（teacher 的关键状态）

**2) 离线 Draft 训练（训练一个便宜的 EA layer / MMModel）**
- 入口：`openvla/specdecoding/train-scripts/train_deepspeed_libero_goal.py`
- 训练数据如何用：
  - 把 `last_layer_hidden_list` 拼成序列 `hidden_state_big=[T,H]`
  - 把 `first_layer_hidden_list` 拼成 `embedding_state=[T,H]`
  - 构造 `target=hidden_state_big` 的 next-step 版本（shift 一位）作为监督
  - `loss_mask` 只在动作 token 段（7 步）计算损失
- Draft 模型：`openvla/specdecoding/model/cnets.py` 的 `MMModel`（配置来自 `llama_2_chat_7B_config.json`，常见 `num_hidden_layers=1`，很浅）
- 训练目标（两项）：
  - hidden 回归：预测 next-step last-layer hidden（SmoothL1）
  - token 蒸馏：把预测 hidden 和 teacher hidden 都过冻结的 `lm_head`，对齐 token 分布

**3) 在线推理整合（Speculative decoding，Draft 提案 + Base 验证）**
- 入口评测脚本：`openvla/experiments/robot/libero/run_libero_goal_Spec.py`（strict）和 `run_libero_goal_Spec_Relaxed.py`（relaxed）
- 模型装配链路：
  - `experiments/robot/openvla_utils.get_vla()` 先加载 OpenVLA base model
  - 再用 `SpecVLAforActionPrediction(base_model=..., ea_model_path=..., accept_threshold=...)` 包一层（定义在 `openvla/prismatic/extern/hf/modeling_speculation.py`）
  - `ea_layer` 就是训练好的 `MMModel` 权重（Draft）
- 推理时每一步的核心循环（`SpecVLAforActionPrediction.eagenerate`）：
  1) **Draft**：`ea_layer.topK_genrate(...)` 基于当前前缀 hidden/embedding 生成一棵候选 token tree（返回 `draft_tokens/retrieve_indices/tree_mask/tree_position_ids`）
  2) **Verify**：把 `tree_mask` 注入 base LLM 的 attention，使其并行算出候选分支 logits
  3) **Accept**：`evaluate_posterior` 决定接受多长前缀 `accept_length` 和选哪条分支 `best_candidate`
     - 关键创新点：`accept_threshold` 允许 `|candidate_token - argmax_token| <= threshold`，把动作 token 的“bin 邻近”当作可接受（见 `openvla/prismatic/extern/hf/utils.py`）
  4) **Update**：更新 `input_ids` 与 KV cache，进入下一轮，直到生成够 7 个动作 token

**4) 输出动作**
- 生成到的动作 token（7 个）按 OpenVLA 的 bin 映射反解成连续动作并反归一化（base 与 spec wrapper 都有同样的 decode 逻辑）。
